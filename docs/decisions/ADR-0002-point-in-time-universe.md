# ADR-0002: No current-rank substitution

- **Status:** Accepted.
- **Decision:** Historical ranks must use market-cap information effective and available by each historical snapshot.
- **Reason:** Current ranks introduce look-ahead and survivorship bias; a permanent top-N universe contradicts the expanding-universe design.
- **Consequence:** If free historical point-in-time cap evidence is unavailable, block empirical backtesting rather than weaken the protocol.
