# Research orchestration

1. Read AGENTS.md, HANDOFF.md, run manifest, universe frontier, frozen grid and protocol before changing research behavior.
2. Run offline checks first. Inspect git status and prior evidence before repeating a probe.
3. Select the highest-priority task that can be completed with evidence. If a data gate is blocked, work on deterministic code, schemas, known-answer tests, or a materially different free source; do not loop on the same failure.
4. Distinguish specification validity, implementation correctness, historical-data readiness, evaluation validity and economic outcome.
5. A worker exit or green CI is not a research result.
6. Make small commits; verify the remote branch head after checkpointing. A local commit alone is not verified persistence.
7. Update HANDOFF.md with changed files, exact commands/results, artifact hashes, blockers and one measurable next task.
8. Do not run empirical evaluation until all required data and specification gates pass.
